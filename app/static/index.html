新建对照批次

只接受单条只读 SELECT。同一「可重复读 · 只读」事务内按 默认 → 关闭 NestLoop → 关闭 NestLoop → 默认（第二轮颠倒顺序）各执行一次 EXPLAIN (ANALYZE, FORMAT JSON)，共 4 次、共享同一快照； 单次执行限时 10 秒；同时只运行一批，满额会提示繁忙。 运行中可在下方「锁等待观察」里分清是计划慢还是表锁阻塞。

补记样表数据

对照运行期间也可正常入库；对照事务使用同一快照，新补记的行不会进入本批结果。

锁等待观察

批次运行期间由独立采样连接每 1 秒读取 pg_locks 与 pg_stat_activity，沿 pg_blocking_pids() 向上追踪阻塞会话链，显示等待对象、阻塞方 PID 和 SQL 摘要；阻塞方自己也在等待时继续向上， 直到锁持有者。每个 PID 都会用会话启动时间核对：会话已退出、PID 被复用或链条断开时 标为无法确认，不会把旧会话当作当前阻塞方。批次超时/取消/结束后保留最后一次确认的链 并标注为历史观察；采样失败只表示状态未知，不等于「无阻塞」。
